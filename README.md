# CLIA State Requirements (50-state dataset)

A free, open dataset of what each US state adds on top of federal CLIA (42 CFR Part 493) for clinical laboratories: which agency processes the CMS-116, whether the state licenses the lab itself, and whether it licenses laboratory personnel.

Maintained by [Sound Lab Consultants](https://soundlabconsult.com), a clinical laboratory consulting team. Each state row links to a state guide with the full requirements and official sources.

- **Data:** [`data/clia-state-requirements.json`](data/clia-state-requirements.json) and [`data/clia-state-requirements.csv`](data/clia-state-requirements.csv)

## Fields

| Field | Meaning |
|---|---|
| `state`, `slug` | State name and URL slug |
| `site` | State guide with full requirements |
| `clia_exempt_state` | `true` for New York and Washington, which run their own programs in place of federal CLIA certification for most labs |
| `clia_state_agency`, `agency_url` | Agency that processes CLIA applications and surveys for CMS |
| `state_facility_license` | `required`, `required_with_exemptions`, `not_required`, `not_described`, or a CLIA-exempt state value |
| `facility_license_summary` | One-sentence summary with the statute or rule where available |
| `personnel_license` | `yes`, `no`, `directors`, or `not_described` |
| `personnel_summary`, `note` | Extra detail |
| `sources` | Official pages the summary is based on |

## Using it

```js
const states = await fetch("https://raw.githubusercontent.com/mylabcompliance/clia-state-requirements/main/data/clia-state-requirements.json").then(r => r.json());
const licensed = states.filter(s => s.state_facility_license.startsWith("required"));
```

## Regulation watch

`bots/state_watch.py` runs daily (GitHub Actions) and checks each state's clinical laboratory regulator page, the official sources behind each state record, New York's CLEP pages (test approval, Single Use Permits, laws, standards, news) and the CMS/CDC CLIA pages. It records new text and newly published documents in [`data/state-watch.json`](data/state-watch.json) and opens an issue for human review when something changes. [Sound Lab Consultants](https://soundlabconsult.com/state-lab-requirements/) shows the latest check and detected changes on each state's requirements page.
